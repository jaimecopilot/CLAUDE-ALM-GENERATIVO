# Biblioteca del curso original «IA aplicada al ciclo de vida del software»

**Fuente:** [jaimecopilot/ia-alm-2026](https://github.com/jaimecopilot/ia-alm-2026).

Los archivos en este directorio reproducen los documentos Markdown de la rama principal del repositorio original, en su estructura de carpetas, con fines de consulta docente y trazabilidad. El repositorio de origen no se modifica.

**Atención:** el curso original contiene tanto teoría como metaprompts que piden a una IA diseñar un ejercicio para el formador. Esos metaprompts **no** son equivalentes a los metaprompts operativos de este taller: estos últimos deben generar instrucciones que produzcan artefactos ALM verificables en el proyecto real.

Para seguir el taller de 16 horas empieza por [01_ALUMNOS](../01_ALUMNOS/README.md), no por esta biblioteca completa.

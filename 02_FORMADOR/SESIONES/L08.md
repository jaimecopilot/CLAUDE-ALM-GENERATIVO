# Guion L08 — Cambio de requisito y propagación (120 min)

## Competencia
El alumno aprende que el mantenimiento puede reabrir especificación, diseño, código y tests. No se ejecuta un segundo proyecto: se modifica el mismo Coworking Manager.

## Minutaje
- 000–015: nueva petición del cliente y diferencia cambio/bug/refactorización.
- 015–035: issue CAM-01 e impacto por artefacto.
- 035–055: metaprompt, prompt operativo y revisión de plan.
- 055–090: ejecución del cambio en código y documentación.
- 090–110: regresión, nuevos tests, GitLab CI.
- 110–120: MR, trazabilidad y aprobación.

## Mensaje del cliente (leer literalmente)
«Ninguna reserva podrá durar más de cuatro horas consecutivas. Exactamente cuatro horas sí se admiten. El resto de reglas se mantiene». No introducir excepciones que el cliente no ha solicitado.

## Demostración del análisis de impacto
En pizarra escribe RF/CA, función de validación, endpoint, tests y documentación. Pide a Claude primero la lista de afectados y qué queda intacto. No permitas que reescriba todo el repositorio; el objetivo es comprobar el *alcance mínimo* del cambio.

## Casos de prueba
- 3h59 de duración en una sala libre: aceptada.
- 4h exactas: aceptada.
- 4h01: rechazada.
- Dos reservas solapadas de corta duración: siguen rechazándose.
- Cancelar una reserva: sigue liberando el intervalo.
Revisa comparaciones en límites y tratamiento de fechas con zona.

## Errores habituales
Claude crea un requisito adicional de autorización para reservas largas; rechazarlo. Claude incorpora una regla de cuatro horas pero cambia el comportamiento de horarios contiguos; regresión. Claude modifica tests para que el viejo código pase; rechazo. El YAML CI pasa localmente pero no hay runner; registrar bloqueo.

## Preguntas
**¿Es un bug que antes se permitiesen 5h?** No, antes no existía ese requisito. **¿Hay que editar el ADR siempre?** Solo si cambia una decisión arquitectónica; no por cualquier funcionalidad nueva. **¿Qué artefacto muestra el alcance del cambio?** Análisis de impacto y MR.

## Gate
Nueva especificación, pruebas de frontera, regresión, MR y CI o bloqueo documentado. Los alumnos explican cómo el requisito viajó por el ALM.
